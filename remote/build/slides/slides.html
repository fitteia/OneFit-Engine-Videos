onefite-gui -ssh · options

Shape the remote session

-remote-addr

The remote GUI's own address: a different one for each account or server, so sessions never collide.

-idle-timeout

Stops the remote GUI once nobody has used it for that long, with no fit or download running.

Your SSH settings

Host aliases, keys, agents and jump hosts work as usual; -ssh-bin picks the SSH client.

Tied together

Close the launcher, or lose the connection, and the remote OFE-GUI stops too.

An OFE-GUI already running

Open the tunnel yourself

For example a server that runs OFE-GUI as a system service, on 127.0.0.1:8143
$ ssh -N -L 18143:127.0.0.1:8143 ofe@server

In your browser

Open http://127.0.0.1:18143 and use the server's OFE-GUI, as with -ssh.

In your own OFE-GUI

Settings → Remote onefite-gui: http://127.0.0.1:18143, as with -connect-remote.

Which one?

Pick by where things should run

-ssh
everything on the remote host: interface, Terminal, files and fits
-connect-remote
interface, Terminal and files here; fits on the remote host
ssh -L
an OFE-GUI already running on the server
-reverse-ssh
the fitting machine can't accept connections
http:// engine
an engine web service, with a smaller set of options
OFE-GUI always listens on 127.0.0.1, and SSH does the connecting. -allow-public exists only for an isolated, firewalled machine: there is no login.
