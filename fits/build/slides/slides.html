What OFE fits

Model + data files

A model expression, with starting values and limits, and one or more data files.

A saved fit

A .json (or an older .sav) that holds the model, the data and the results.

A batch

Several saved fits, or a jobs file with one fit per line, run in parallel.

A batch · OFE-Go

Many fits, one command

$ cat fits.txt # one fit per line: TAB-separated fields Mz(t,M0:1,Minf:0.05,T1:2[0.01<100])=Minf+(M0-Minf)*exp(-t/T1)→T005F1_1.sdf→--individual Mz(t,M0:1,Minf:0.05,T1:2[0.01<100],b:0.9[0.3<1])=Minf+(M0-Minf)*exp(-pow(t/T1,b))→T005F1_1.sdf→--individual t005.json→--global
$ onefite fit @fits.txt --jobs=2 --reduced-chi2 --fit-methods='simp scan min' --wf=results ===> 3 fits, 2 at once (2 workers each), in results/batch-20261027-090858 fit-T005F1_1-individual done 0.7 s chi2 0.048264855 fit-T005F1_1-individual-2 done 0.8 s chi2 0.050190554 t005-global done 0.3 s chi2 41.076165 ===> 3 done, 0 failed, 0 stopped - results/batch-20261027-090858/batch.json
onefite fit a.json b.json c.json runs saved fits the same way
Parallel fits

Two levels of parallel work

Inside one fit

An individual fit runs its blocks at the same time; a hybrid fit, its per-block parts.

--workers=N caps them, at the CPUs by default; --no-parallel runs one at a time. OFE-GUI: Workers, parallel.

Across fits

A batch runs --jobs fits at once, as many as the CPUs by default. OFE-GUI: Fits at once.

Each fit gets CPUs ÷ jobs workers, unless you set --workers: 4 CPUs, 2 at once, 2 workers each.

Parallel fits run with the engine on OFE-GUI's own machine: on your computer, or on the server with -ssh.
